# IA responsable

| Principio | Evidencia del prototipo |
|---|---|
| Equidad | Casos dorados en español y contratos iguales por categoría |
| Confiabilidad | Degradación a reglas locales y revisión humana |
| Privacidad | Datos sintéticos, minimización y archivos locales excluidos de Git |
| Inclusión | Diseño responsivo, etiquetas y navegación con controles nativos |
| Transparencia | Aviso de IA, precios base y estados tentativos visibles |
| Rendición de cuentas | Tareas, identidad del revisor y auditoría |

El modelo no debe decidir disponibilidad, precio final o pago. El contenido recuperado se considera evidencia no confiable y no puede cambiar instrucciones ni activar herramientas.
