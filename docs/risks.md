# Registro de riesgos

| Riesgo | Mitigación |
|---|---|
| Fuente Kyte no autorizada | Importación controlada; no scraping productivo |
| Precio base confundido con final | Etiquetas y aprobación humana |
| Fecha tentativa confundida con confirmada | Estados explícitos y revisión humana |
| Contenido malicioso en RAG/OCR | Separación datos/instrucciones y filtros |
| Error OCR | Baja confianza y revisión |
| Costo Azure | Presupuesto, SKU pequeño y apagado documentado |
| API preview Foundry cambia | ADR, validación previa y versiones fijadas |
