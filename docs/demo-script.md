# Guion de demostración

1. Abrir `/` y explicar el aviso de IA.
2. Mostrar las tres categorías y un enlace Kyte de demostración.
3. Preguntar por existencias y observar la aclaración sobre trabajo bajo pedido.
4. Preguntar por entrega en zona centro y mostrar citas.
5. Crear una solicitud personalizada.
6. Abrir `/admin` y mostrar la tarea de disponibilidad.
7. Configurar un slot de calendario y ejecutar la consulta de capacidad desde OpenAPI `/docs`.
8. Aprobar disponibilidad con el rol humano.
9. Cargar un PDF sintético y repetirlo para mostrar duplicado.
10. Mostrar auditoría, pruebas y modo de adaptador.
